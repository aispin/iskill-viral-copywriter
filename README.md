# iskill-viral-copywriter

当用户要写短视频口播稿/带货文案/种草脚本，问「按这个选题写文案」「生成口播稿」「帮我写脚本」「出多平台文案」「小红书/视频号/抖音版文案」时使用。触发词：写文案、口播稿、短视频脚本、文案生成、带货文案、多平台文案、四套文案。输入 iskill-hot-topic-scout 的选题卡和可选的 iskill-viral-teardown 拆解报告，按爆款结构产出**默认四套**（通用 + 小红书 + 微信视频号 + 抖音）15s/30s/60s 完整口播稿，每套配该平台发布文案（标题/描述/标签）。

完整用法见 [SKILL.md](SKILL.md)。

> 依赖同步：本仓库含 iskill 共享真源的 vendored 副本（清单见 `package.json` 的 `iskillDeps`），**不要手改**。使用前请同时安装 iskill-utils：对 agent 说「请帮我安装 Skill：aispin/iskill-utils」；用法见 SKILL.md「依赖同步」节。
